# Todo App

A modern, full-stack todo app built with Next.js 16 and a professional-grade stack.

## ✨ Features

- **Authentication** — Email/password sign-up and sign-in with secure session cookies
- **Create, toggle, and delete todos** — Instant UI updates
- **Filters** — View all, active, or completed tasks
- **Optimistic UI** — Actions feel instant
- **Glassmorphic design** — Modern, clean, responsive
- **Dark-proof styling** — Soft gradient background with blurred accents

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Framework** | Next.js 16 (App Router) + TypeScript |
| **Database** | Neon (serverless Postgres) |
| **ORM** | Drizzle |
| **Authentication** | Custom session-based auth with bcrypt + JWT cookies |
| **Server State** | TanStack Query |
| **Client State** | Zustand |
| **Forms** | React Hook Form + Zod |
| **Styling** | Tailwind CSS |
